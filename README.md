# CCS811-Air-Quality-and-Gas-Sensor-Project-Arduino-

โปรเจกต์นี้เป็นโค้ดสคริปต์ภาษา C++/Arduino สำหรับทดสอบและควบคุมเซนเซอร์ CCS811 ซึ่งเป็นเซนเซอร์วัดค่าก๊าซพิษในอากาศ (TVOCs) และระดับคาร์บอนไดออกไซด์เทียบเท่า (eCO2) แบบดิจิทัล   

โครงสร้างโปรเจกต์ (Project Structure)

ภายในโปรเจกต์ประกอบด้วยไฟล์สำคัญดังนี้:   

test_ccs811.ino: ไฟล์สคริปต์โค้ดหลักของ Arduino ที่ใช้สำหรับติดต่อสื่อสารผ่านโปรโตคอล I2C กับเซนเซอร์ CCS811 อ่านค่าคุณภาพอากาศ และแสดงผลลัพธ์   

อุปกรณ์ที่ต้องใช้ (Hardware Requirements)

บอร์ดไมโครคอนโทรลเลอร์ Arduino (เช่น Arduino UNO, Nano, ESP32 หรือ ESP8266)

โมดูลเซนเซอร์ CCS811 (Gas Sensor สำหรับวัด eCO2 และ TVOC)

สายไฟเชื่อมต่อ (Jumper Wires) และ Breadboard
